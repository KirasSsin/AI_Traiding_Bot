# LLM Wiki — AI Trading Bot

Персональная база знаний, которую ведёт LLM-агент.  
Покрывает две области одновременно:

- **Трейдинг** — стратегии, индикаторы, паттерны, риск-менеджмент, психология рынка.
- **Проект AI Trading Bot** — архитектура, компоненты, эксперименты, бэктесты, решения.

## Идея

Не RAG, а постоянно поддерживаемая wiki. LLM читает новые источники, не просто индексирует их, а **интегрирует** в существующую wiki: обновляет страницы сущностей, правит резюме тем, отмечает противоречия, усиливает или оспаривает текущий синтез. Знание **компилируется один раз** и поддерживается в актуальном состоянии, а не переоткрывается на каждый запрос.

Ключевая связка между областями: страницы проекта (`wiki/project/experiments/`) ссылаются на страницы трейдинга (`wiki/trading/strategies/`) — «эксперимент X тестирует стратегию Y на индикаторе Z».

## Три слоя

1. **Raw** (`raw/`) — immutable источники: статьи, PDF, видео-транскрипты, внутренние доки бота, логи бэктестов, графики. LLM читает, но не модифицирует.
2. **Wiki** (`wiki/`) — markdown-страницы, которые ведёт LLM: резюме, страницы сущностей, концепций, сравнений, связей, обзоры.
3. **Схема** (`CLAUDE.md`) — правила работы LLM: структура wiki, конвенции, workflow для ingest/query/lint.

## Структура

```
llm-wiki/
├── CLAUDE.md              # схема — правила для LLM-мейнтейнера
├── README.md              # этот файл
├── raw/                   # исходники (immutable)
│   ├── trading/           # материалы по трейдингу
│   ├── project/           # внутренние доки бота, бэктесты
│   └── assets/            # изображения, графики
├── wiki/                  # LLM-генерируемые страницы
│   ├── index.md           # каталог всех страниц
│   ├── log.md             # хронологический журнал
│   ├── trading/
│   │   ├── strategies/    # торговые стратегии
│   │   ├── indicators/    # индикаторы
│   │   ├── patterns/      # рыночные паттерны
│   │   └── concepts/      # общие концепции
│   └── project/
│       ├── architecture/  # архитектурные решения
│       ├── experiments/   # эксперименты и бэктесты
│       ├── decisions/     # ADR-подобные записи
│       └── components/    # модули/компоненты бота
└── queries/               # сохранённые ответы на запросы
```

## Операции

- **Ingest** — добавляешь файл в `raw/`, просишь LLM обработать. Агент читает, обсуждает с тобой ключевые выводы, пишет страницу-резюме, обновляет связанные страницы и индекс, добавляет запись в `log.md`.
- **Query** — задаёшь вопрос. LLM читает `index.md`, находит релевантные страницы, синтезирует ответ с цитатами. Ценные ответы можно **сохранять** в `queries/` как новые wiki-страницы.
- **Lint** — периодическая проверка здоровья wiki: противоречия, устаревшие утверждения, страницы-сироты, пропущенные концепции, недостающие кросс-ссылки.

## Навигация

- `wiki/index.md` — content-oriented каталог страниц по категориям.
- `wiki/log.md` — хронологический append-only журнал (`## [YYYY-MM-DD] ingest | Title`).

## Использование с Obsidian

Wiki — это обычный git-репозиторий markdown-файлов. Открывается в Obsidian как vault: graph view покажет структуру связей, Dataview соберёт таблицы по frontmatter, Marp отрендерит презентации из страниц.

## Правила

Вся конкретика — в [CLAUDE.md](CLAUDE.md). Этот файл — высокоуровневое описание идеи.
