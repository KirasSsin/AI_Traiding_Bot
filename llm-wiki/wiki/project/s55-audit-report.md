## 7. Recommended Fix Order

### Wave 0 — Live-path BLOCKERs (gate δ-testnet/demo activation; **sequential, single workstream**)
The live order→fill→protect→exit chain is broken in **three independent places**. None can be skipped; fixing one does not unblock the others. **Do NOT activate any funded/demo account until all three land + the new end-to-end test passes.**

1. **BYBIT-01** — unify REST+WS environment (smallest, unblocks any event flow at all). Sequential first: without this, no fill events arrive to test ARCH-01/TL-01 against.
2. **ARCH-01** — per-thread SQLite connection (or queue). Without this, fill events that DO arrive crash silently.
3. **TL-01 + TL-02** — wire `arm_oco` on entry-fill, `flatten` on FLAT-signal + RECONCILE_DIVERGENCE, `reconcile_arming_ttl` into tick. (TL-02 is the same root cause — one fix.)
