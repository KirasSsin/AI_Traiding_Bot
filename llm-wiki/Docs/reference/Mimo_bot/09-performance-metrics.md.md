## MVP-набор: 15 ключевых метрик

Метрики выбраны для MVP-отчёта (v0.1–v0.3). Каждая покрывает уникальный аспект качества стратегии. Нет дублирования — каждая метрика несёт свою информацию.

### 1. Total Return (Общая доходность)

**Формула:**

$$
R_{total} = \frac{V_{final} - V_{initial}}{V_{initial}} \times 100\%
$$

Где:
- $V_{final}$ — конечная стоимость портфеля
- $V_{initial}$ — начальная стоимость портфеля

**Промежуточные вычисления:**
- $V_{final} = V_{initial} + \sum_{i=1}^{n} PnL_i$ (сумма всех PnL сделок)

| Интерпретация | Значение |
|---|---|
| Хорошо | > 0% (стратегия прибыльна) |
| Отлично (крипта) | > 100% за год |
| Плохо | ≤ 0% (стратегия теряет деньги) |

**Порог:** > 0% (обязательно), > 15% годовых для крипты (с учётом buy & hold BTC как бенчмарк)

**Edge cases:**
- Не учитывает риск — может быть высокой при экстремальном риске
- Зависит от периода тестирования — 1000% за 1 день ≠ 1000% за 10 лет
- Не нормализован — сравнивать можно только за одинаковый период

---

### 2. CAGR (Compound Annual Growth Rate)

**Формула:**

$$
CAGR = \left(\frac{V_{final}}{V_{initial}}\right)^{\frac{1}{years}} - 1
$$

Для периодов менее года:

$$
CAGR = \left(\frac{V_{final}}{V_{initial}}\right)^{\frac{365}{days}} - 1
$$

**Промежуточные вычисления:**
- $years = (date_{end} - date_{start}) / 365.25$
- Если $V_{initial} = 0$ → CAGR не определён

| Интерпретация | Значение |
|---|---|
| Хорошо (крипта) | > 15% годовых |
| Отлично (крипта) | > 50% годовых |
| Плохо | < 0% (убыток) |
| Слишком хорошо (подозрение) | > 500% → проверить на overfitting |

**Порог:** > 15% годовых (минимум для крипты, где buy & hold BTC даёт ~30–60% CAGR исторически)

**Edge cases:**
- На коротких периодах (< 3 месяцев) CAGR экстремально волатилен
- Не учитывает промежуточные пополнения/выводы (нужен TWR/MWR для этого)
- Нулевая начальная сумма → деление на ноль

---

### 3. Sharpe Ratio

**Формула:**

$$
Sharpe = \frac{\bar{R}_p - R_f}{\sigma_p}
$$

Где:
- $\bar{R}_p$ — средняя доходность портфеля за период
- $R_f$ — безрисковая ставка за тот же период
- $\sigma_p$ — стандартное отклонение доходности портфеля

**Промежуточные вычисления:**

$$
\bar{R}_p = \frac{1}{n} \sum_{i=1}^{n} R_i
$$

$$
\sigma_p = \sqrt{\frac{1}{n-1} \sum_{i=1}^{n} (R_i - \bar{R}_p)^2}
$$

**Для крипты:** $R_f = 0$ (или $R_f = USDT lending rate \approx 3–8\%$ годовых)

**Годовой Sharpe (из дневного):**

$$
Sharpe_{annual} = Sharpe_{daily} \times \sqrt{365}
$$

**Для крипты (24/7):** $\sqrt{365}$ вместо $\sqrt{252}$ (рыночных дней акций)

| Интерпретация | Значение |
|---|---|
| Приемлемо | 0.5 – 1.0 |
| Хорошо | 1.0 – 2.0 |
| Отлично | 2.0 – 3.0 |
| Подозрительно (overfitting?) | > 4.0 |

**Порог:** ≥ 1.0 (годовой)

**Edge cases:**
- Штрафует за положительную волатильность (рост = «риск» по Sharpe) — абсурдно для трейдинга
- Предполагает нормальное распределение — крипта имеет fat tails
- На коротких выборках может быть очень высоким случайно
- Стратегия с 50% роста и 40% волатильностью имеет тот же Sharpe, что и 5% роста с 4% волатильностью

---

### 4. Sortino Ratio

**Формула:**

$$
Sortino = \frac{\bar{R}_p - R_f}{\sigma_d}
$$

Где $\sigma_d$ — downside deviation (только отрицательные доходности):

$$
\sigma_d = \sqrt{\frac{1}{n} \sum_{i=1}^{n} min(R_i - MAR, 0)^2}
$$

$MAR$ (Minimum Acceptable Return) = $R_f$ или 0.

**Промежуточные вычисления:**
1. Для каждого периода: $d_i = min(R_i - MAR, 0)$
2. Сумма квадратов: $SS_d = \sum d_i^2$
3. Downside deviation: $\sigma_d = \sqrt{SS_d / n}$
4. Sortino = $(\bar{R}_p - MAR) / \sigma_d$

| Интерпретация | Значение |
|---|---|
| Приемлемо | 1.0 – 1.5 |
| Хорошо | 1.5 – 2.5 |
| Отлично | 2.5 – 4.0 |
| Исключительно | > 4.0 |

**Порог:** ≥ 1.5

**Edge cases:**
- Если нет отрицательных доходностей → $\sigma_d = 0$ → Sortino = ∞ (бессмысленно)
- MAR = 0 vs MAR = Rf дают разные результаты — нужно быть консистентным
- На коротких выборках с малым числом убыточных периодов — нестабилен

---

### 5. Calmar Ratio

**Формула:**

$$
Calmar = \frac{CAGR}{|MaxDD|}
$$

Где:
- $CAGR$ — среднегодовая доходность
- $MaxDD$ — максимальная просадка (как дробь, не процент)

**Промежуточные вычисления:**
1. $CAGR = (V_{final}/V_{initial})^{1/years} - 1$
2. $MaxDD$ — вычисляется отдельно (см. метрику #8)
3. $Calmar = CAGR / |MaxDD|$

| Интерпретация | Значение |
|---|---|
| Приемлемо | 0.5 – 1.0 |
| Хорошо | 1.0 – 2.0 |
| Отлично | 2.0 – 3.0 |
| Исключительно | > 3.0 |

**Порог:** ≥ 1.0 (доходность компенсирует просадки)

**Edge cases:**
- На коротких периодах CAGR может быть аномальным → Calmar нестабилен
- MaxDD = 0% (теоретически невозможно на практике, но если → ∞)
- Не различает глубокую кратковременную и мелкую длительную просадку

---

### 6. Maximum Drawdown (Максимальная просадка)

**Формула:**

$$
MaxDD = \max_{t \in [0,T]} \left( \frac{Peak_t - Valley_t}{Peak_t} \right)
$$

Где:
- $Peak_t$ — максимальное значение Equity на момент $t$ (running maximum)
- $Valley_t$ — минимальное значение Equity после $Peak_t$

**Промежуточные вычисления:**
1. $Equity_t = V_{initial} + \sum_{i=1}^{t} PnL_i$ (кумулятивная кривая капитала)
2. $Peak_t = \max(Equity_1, Equity_2, ..., Equity_t)$
3. $Drawdown_t = (Peak_t - Equity_t) / Peak_t$
4. $MaxDD = \max(Drawdown_1, ..., Drawdown_T)$

| Интерпретация | Значение |
|---|---|
| Отлично | < 10% |
| Хорошо | 10 – 20% |
| Приемлемо | 20 – 30% |
| Опасно | 30 – 50% |
| Катастрофа | > 50% |

**Порог:** < 25% (обязательно)

**Edge cases:**
- Зависит от периода — чем длиннее, тем больше шанс найти глубокую просадку
- Не показывает длительность просадки — 25% за день vs 25% за 6 месяцев
- Точка-to-точка: зависит от начальной точки (начало в пике vs начало в просадке)

---

### 7. Win Rate (Процент прибыльных сделок)

**Формула:**

$$
WinRate = \frac{N_{win}}{N_{total}} \times 100\%
$$

Где:
- $N_{win}$ — количество прибыльных сделок ($PnL_i > 0$)
- $N_{total}$ — общее количество сделок

**Промежуточные вычисления:**
- $N_{loss} = N_{total} - N_{win}$
- $LossRate = 1 - WinRate$

| Интерпретация | Значение |
|---|---|
| Хорошо | 50 – 60% |
| Отлично | 60 – 70% |
| Скальпинг | 70 – 85% (маленькие прибыли, редкие крупные потери) |
| Трендовая | 35 – 50% (крупные прибыли, частые мелкие потери) |

**Порог:** > 45% (базовый), но зависит от Payoff Ratio

**Связь с Profit Factor:**

$$
ProfitFactor = \frac{WinRate \times AvgWin}{(1 - WinRate) \times AvgLoss}
$$

**Edge cases:**
- Высокий Win Rate ≠ прибыльность (можно выигрывать 95% сделок по $1 и проигрывать 5% по $1000)
- Малое количество сделок → Win Rate ненадёжен статистически (нужно ≥ 30)
- Breakeven Win Rate зависит от Payoff Ratio: $WR_{min} = \frac{1}{1 + Payoff}$

---

### 8. Profit Factor

**Формула:**

$$
PF = \frac{\sum PnL_{win}}{|\sum PnL_{loss}|}
$$

Где:
- $\sum PnL_{win}$ — сумма всех прибыльных сделок
- $\sum PnL_{loss}$ — сумма всех убыточных сделок (абсолютное значение)

**Альтернативная формула:**

$$
PF = \frac{WinRate \times AvgWin}{LossRate \times AvgLoss}
$$

| Интерпретация | Значение |
|---|---|
| Убыточная | < 1.0 |
| Breakeven | = 1.0 |
| Приемлемо | 1.0 – 1.5 |
| Хорошо | 1.5 – 2.0 |
| Отлично | 2.0 – 3.0 |
| Исключительно | > 3.0 |

**Порог:** > 1.5

**Edge cases:**
- Если нет убыточных сделок → PF = ∞ (бессмысленно)
- Чувствителен к выбросам — одна крупная прибыль может завысить PF
- Не учитывает распределение прибылей/убытков (только суммы)

---

### 9. Expectancy (Математическое ожидание)

**Формула:**

$$
E = WinRate \times AvgWin - LossRate \times AvgLoss
$$

Где:
- $AvgWin = \frac{\sum PnL_{win}}{N_{win}}$
- $AvgLoss = \frac{|\sum PnL_{loss}|}{N_{loss}}$

**Нормализованная версия (в % от риска):**

$$
E_{norm} = \frac{E}{AvgRisk} \times 100\%
$$

| Интерпретация | Значение |
|---|---|
| Убыточная | < 0 |
| Breakeven | = 0 |
| Хорошо | > 0 |
| Отлично (крипта) | > 0.5% от капитала на сделку |

**Порог:** > 0 (обязательно), > 0.5% от капитала для крипты

**Edge cases:**
- Валютозависима — нужно нормализовать (%, пункты, R-multiple)
- Зависит от частоты торговли — E × Trades/Year = реальная прибыль
- Малое количество сделок → E ненадёжен

---

### 10. Recovery Factor

**Формула:**

$$
RF = \frac{Net Profit}{MaxDD}
$$

Где:
- $Net Profit = V_{final} - V_{initial}$
- $MaxDD$ — максимальная просадка в абсолютном выражении

| Интерпретация | Значение |
|---|---|
| Плохо | < 1.0 (не отыграла просадку) |
| Приемлемо | 1.0 – 3.0 |
| Хорошо | 3.0 – 5.0 |
| Отлично | > 5.0 |

**Порог:** > 3.0

**Edge cases:**
- MaxDD = 0 → RF = ∞
- Зависит от периода — длинный период обычно даёт более глубокий MaxDD
- Не показывает скорость восстановления

---

### 11. Payoff Ratio (Соотношение прибыли/убытков)

**Формула:**

$$
Payoff = \frac{AvgWin}{AvgLoss}
$$

| Интерпретация | Значение |
|---|---|
| Плохо | < 1.0 (средний убыток > средней прибыли) |
| Breakeven | = 1.0 |
| Хорошо | 1.2 – 2.0 |
| Отлично | > 2.0 |

**Порог:** > 1.2

**Связь с Win Rate (Breakeven точка):**

$$
WR_{breakeven} = \frac{1}{1 + Payoff}
$$

| Payoff | Min Win Rate |
|---|---|
| 1.0 | 50% |
| 1.5 | 40% |
| 2.0 | 33.3% |
| 3.0 | 25% |

**Edge cases:**
- Мало сделок → одно крупное выигрышное/проигрышное может исказить
- Стратегия может иметь Payoff < 1, но быть прибыльной при высоком Win Rate

---

### 12. Omega Ratio

**Формула:**

$$
\Omega = \frac{\int_{\theta}^{\infty} (1 - F(x)) dx}{\int_{-\infty}^{\theta} F(x) dx}
$$

Где:
- $F(x)$ — кумулятивная функция распределения доходностей
- $\theta$ — порог (threshold), обычно 0

**Дискретная версия (для бэктеста):**

$$
\Omega = \frac{\sum_{i: R_i > \theta} (R_i - \theta)}{\sum_{i: R_i < \theta} (\theta - R_i)}
$$

| Интерпретация | Значение |
|---|---|
| Убыточная | < 1.0 |
| Хорошо | 1.0 – 1.5 |
| Отлично | > 1.5 |

**Порог:** > 1.0

**Edge cases:**
- Все доходности > θ → знаменатель = 0 → Ω = ∞
- Все доходности < θ → числитель = 0 → Ω = 0
- Чувствителен к выбросам в обе стороны
- Преимущество: учитывает ВСЁ распределение, не только среднее и дисперсию

---

### 13. Max Consecutive Losses (Максимальная серия убытков)

**Формула:**

$$
MCL = \max_{t} \left( \text{длина серии } i, i+1, ..., i+k \text{ где } PnL_j < 0 \text{ для всех } j \right)
$$

| Интерпретация | Значение |
|---|---|
| Отлично | < 3 |
| Хорошо | 3 – 5 |
| Приемлемо | 5 – 8 |
| Опасно | > 8 |
| Психологическая катастрофа | > 12 |

**Порог:** < 8

**Edge cases:**
- Мало сделок → серия может быть случайной
- Зависит от масштаба потерь (серия из 10 потерь по $10 vs 1 потерь по $10000)
- Стресс-тест: если серия = 50% от общего количества сделок → проблема

---

### 14. Average Holding Time (Среднее время в сделке)

**Формула:**

$$
AHT = \frac{1}{n} \sum_{i=1}^{n} (t_{exit,i} - t_{entry,i})
$$

| Интерпретация | Значение |
|---|---|
| Скальпинг | < 1 час |
| Интрадей | 1 – 24 часа |
| Свинг | 1 – 7 дней |
| Позиционная | > 7 дней |

**Порог:** Зависит от таймфрейма стратегии (нет универсального порога)

**Edge cases:**
- Незакрытые сделки → не учитывать или считать до текущего момента
- Включает выходные (крипта 24/7) — отличается от акций
- Экстремально длинные сделки (месяцы) могут искажать среднее — лучше медиану

---

### 15. Num Trades (Количество сделок)

**Формула:**

$$
N = \text{count}(trades)
$$

| Интерпретация | Значение |
|---|---|
| Недостаточно для статистики | < 30 |
| Минимум для базовой значимости | 30 – 50 |
| Хорошо | 50 – 200 |
| Много (проверить комиссии) | > 200 |

**Порог:** ≥ 30 (статистическая значимость для большинства тестов)

**Edge cases:**
- Слишком много сделок → комиссии могут съедать прибыль
- Слишком мало → метрики ненадёжны
- 29 сделок с Sharpe 3.0 менее надёжны, чем 200 сделок с Sharpe 1.5

## Полный каталог метрик

Дополнительные метрики (вне MVP-15), которые добавляют ценность:

### 16. Ulcer Index (UI)

**Формула:**

$$
UI = \sqrt{\frac{1}{n} \sum_{i=1}^{n} DD_i^2}
$$

Где $DD_i = \frac{Peak_i - Equity_i}{Peak_i} \times 100$ — процентная просадка от пика.

**Интерпретация:** Чем ниже, тем лучше. UI = 0 означает отсутствие просадок. UI = 20 означает «средняя» просадка ~20%.

| Значение | Оценка |
|---|---|
| < 5 | Отлично |
| 5 – 10 | Хорошо |
| 10 – 20 | Приемлемо |
| > 20 | Плохо |

**Порог:** < 15

**Edge cases:**
- Всегда > 0 (если были хоть какие-то просадки)
- Чувствителен к длительности просадок (длительные = выше UI)

---

### 17. Sterling Ratio

**Формула:**

$$
Sterling = \frac{CAGR}{|AvgDD_k|}
$$

Где $AvgDD_k$ — среднее из $k$ наибольших просадок (обычно $k = 3$).

**Интерпретация:** Как Calmar, но использует среднее из нескольких крупных просадок вместо только максимальной. Более стабильна.

| Значение | Оценка |
|---|---|
| < 0.5 | Плохо |
| 0.5 – 1.0 | Приемлемо |
| 1.0 – 2.0 | Хорошо |
| > 2.0 | Отлично |

**Порог:** ≥ 1.0

**Edge cases:**
- Зависит от выбора $k$ — нужно быть консистентным
- Если просадок < $k$ → используем все доступные

---

### 18. Burke Ratio

**Формула:**

$$
Burke = \frac{R_p}{\sqrt{\sum_{i=1}^{k} DD_i^2}}
$$

Где:
- $R_p$ — доходность портфеля
- $DD_i$ — $i$-я наибольшая просадка
- $k$ — количество просадок для учёта (обычно $k = 2$)

**Интерпретация:** Как Calmar/Sterling, но штрафует за кумулятивный эффект просадок. Выше = лучше.

**Порог:** > 0.5

**Edge cases:**
- Много мелких просадок могут дать тот же результат, что и одна крупная

---

### 19. Tail Ratio

**Формула:**

$$
Tail = \frac{|Percentile_{95}(returns)|}{|Percentile_{5}(returns)|}
$$

**Интерпретация:** Соотношение «правого хвоста» (крупных прибылей) к «левому хвосту» (крупных убытков). > 1.0 = правый хвост длиннее.

| Значение | Оценка |
|---|---|
| < 1.0 | Левый хвост длиннее (опасно) |
| 1.0 – 1.5 | Сбалансировано |
| > 1.5 | Правый хвост длиннее (хорошо) |

**Порог:** > 1.0

**Edge cases:**
- Зависит от выбора перцентилей (95/5 стандарт, но можно 99/1)
- На коротких выборках перцентили нестабильны

---

### 20. Gain-to-Pain Ratio (GPR)

**Формула:**

$$
GPR = \frac{\sum R_i}{\sum |min(R_i, 0)|}
$$

Где $R_i$ — доходность за период $i$.

**Интерпретация:** Аналог Profit Factor для периодов (не сделок). Отношение общей прибыли к общей «боли» (убыткам).

| Значение | Оценка |
|---|---|
| < 1.0 | Убыточная |
| 1.0 – 1.5 | Приемлемо |
| > 1.5 | Хорошо |

**Порог:** > 1.5

---

### 21. K-Ratio

**Формула:**

$$
K = \frac{\beta}{SE(\beta)}
$$

Где:
- $\beta$ — наклон линейной регрессии кумулятивной кривой капитала по времени
- $SE(\beta)$ — стандартная ошибка наклона

**Интерпретация:** Измеряет консистентность роста капитала. Высокий K-Ratio = стабильный, линейный рост (идеал).

| Значение | Оценка |
|---|---|
| < 1.0 | Неконсистентный рост |
| 1.0 – 2.0 | Приемлемо |
| > 2.0 | Консистентный рост |

**Порог:** > 1.0

**Edge cases:**
- Линейная модель не подходит для стратегий с «ступенчатым» ростом
- Штрафует стратегии с редкими, но крупными выигрышами

---

### 22. Information Ratio

**Формула:**

$$
IR = \frac{R_p - R_b}{\sigma_{p-b}}
$$

Где:
- $R_p$ — доходность портфеля
- $R_b$ — доходность бенчмарка (buy & hold BTC)
- $\sigma_{p-b}$ — стандартное отклонение разницы доходностей (tracking error)

**Интерпретация:** Насколько стратегия превосходит бенчмарк с поправкой на отклонение от него.

| Значение | Оценка |
|---|---|
| < 0 | Хуже бенчмарка |
| 0 – 0.5 | Слабый альфа |
| 0.5 – 1.0 | Хороший альфа |
| > 1.0 | Отличный альфа |

**Порог:** > 0 (превосходит бенчмарк)

**Edge cases:**
- Требует определения бенчмарка (BTC buy & hold? ETH? индекс?)
- Не имеет смысла без бенчмарка

---

### 23. Treynor Ratio

**Формула:**

$$
Treynor = \frac{R_p - R_f}{\beta_p}
$$

Где $\beta_p$ — бета портфеля относительно рынка.

**Интерпретация:** Доходность за единицу систематического риска. Применимо в основном к портфелям акций.

**Для крипты:** Ограниченная применимость — бета крипто-активов часто > 2.0 и нестабильна.

**Порог:** Не используется для MVP (менее релевантен для крипто)

---

### 24. Jensen's Alpha

**Формула:**

$$
\alpha = R_p - [R_f + \beta_p \times (R_m - R_f)]
$$

Где:
- $R_m$ — доходность рынка
- CAPM-модель используется для определения ожидаемой доходности

**Интерпретация:** Абсолютная альфа — доходность выше/ниже CAPM-прогноза.

**Для крипты:** CAPM плохо работает на крипте (неэффективный рынок, нет единого «безрискового» актива).

**Порог:** Не используется для MVP

---

### 25. R-Squared (Коэффициент детерминации)

**Формула:**

$$
R^2 = 1 - \frac{\sum (R_i - \hat{R}_i)^2}{\sum (R_i - \bar{R})^2}
$$

Или для корреляции с бенчмарком:

$$
R^2 = Corr(R_p, R_b)^2
$$

**Интерпретация:** Какая доля доходности объясняется бенчмарком (систематический риск) vs альфой.

| Значение | Интерпретация |
|---|---|
| > 0.75 | Стратегия сильно коррелирует с рынком (мало альфы) |
| 0.25 – 0.75 | Смесь альфы и бета |
| < 0.25 | Стратегия независима от рынка (альфа) |

**Порог:** Информативная метрика, не пороговая

**Edge cases:**
- Низкий R² ≠ плохо — может означать настоящую альфу
- Высокий R² ≠ плохо — может означать дешёвый рынко-следящий инструмент

---

### 26. Serenity Ratio

**Формула:**

$$
Serenity = \frac{R_p}{UI \times \sqrt{\sum DD_i^2}}
$$

Где:
- $R_p$ — доходность портфеля
- $UI$ — Ulcer Index

**Интерпретация:** Комбинирует доходность с «болезненностью» просадок. Чем выше, тем комфортнее торговля.

**Порог:** > 1.0

---

### 27. Average Drawdown

**Формула:**

$$
AvgDD = \frac{1}{k} \sum_{i=1}^{k} DD_i
$$

Где $DD_i$ — $i$-я просадка (все просадки > порога).

**Интерпретация:** Средняя «глубина» просадок. Дополняет MaxDD.

**Порог:** < 10% (средняя просадка не должна быть слишком болезненной)

---

### 28. Maximum Drawdown Duration

**Формула:**

$$
MaxDD_{dur} = \max_{i} (t_{recovery,i} - t_{peak,i})
$$

Где:
- $t_{peak,i}$ — момент начала $i$-й просадки
- $t_{recovery,i}$ — момент восстановления до пика

**Интерпретация:** Как долго портфель «сидит в просадке». Для крипты — критична.

| Значение | Оценка |
|---|---|
| < 7 дней | Отлично |
| 7 – 30 дней | Хорошо |
| 30 – 90 дней | Приемлемо |
| > 90 дней | Проблема |

**Порог:** < 90 дней (для крипты)

**Edge cases:**
- Если просадка не была восстановлена → MaxDD Duration = текущий период - время начала
- Зависит от таймфрейма торговли (для свинга 90 дней — много, для позиционной — нормально)

---

### 29. Pain Index

**Формула:**

$$
PI = \frac{1}{n} \sum_{i=1}^{n} \frac{Peak_i - Equity_i}{Peak_i}
$$

**Интерпретация:** Средняя просадка по всем точкам. Похож на Ulcer Index, но без возведения в квадрат.

**Порог:** < 10%

---

### 30. Deflated Sharpe Ratio (DSR)

**Формула:**

$$
DSR = Z\left[ \frac{(SR - E[SR])}{\sqrt{Var(SR)}} \right]
$$

С поправкой на множественное тестирование:

$$
E[SR] \approx \sqrt{\frac{2}{N}} \times E\left[\sqrt{\chi^2_1}\right]
$$

Где:
- $SR$ — наблюдаемый Sharpe Ratio
- $N$ — количество протестированных стратегий
- $Z[\cdot]$ — CDF стандартного нормального распределения

**Интерпретация:** Sharpe Ratio, скорректированный на множественное тестирование (сколько стратегий было протестировано перед выбором лучшей).

**Порог:** > 0 (стратегия статистически значима после поправки)

**Edge cases:**
- Требует оценку $N$ (сколько стратегий тестировали) — часто неизвестно
- Отложен до v0.5

---

### 31. Probabilistic Sharpe Ratio (PSR)

**Формула:**

$$
PSR = Z\left[ \frac{(SR - SR^*) \sqrt{n-1}}{\sqrt{1 - \gamma_3 SR + \frac{\gamma_4 - 1}{4} SR^2}} \right]
$$

Где:
- $SR^*$ — минимальный Sharpe (бенчмарк, обычно 0)
- $\gamma_3$ — асимметрия доходностей
- $\gamma_4$ — эксцесс доходностей
- $n$ — количество наблюдений

**Интерпретация:** Вероятность того, что истинный Sharpe > $SR^*$. Учитывает не-нормальность распределения.

**Порог:** > 0.95 (95% уверенность, что Sharpe > 0)

## Overfitting Detection

Переобучение — главный враг алготрейдинга. Как обнаружить через метрики:

### 1. In-Sample vs Out-of-Sample Sharpe Decay

**Метод:**

1. Разделить данные: 70% in-sample (IS), 30% out-of-sample (OOS)
2. Оптимизировать параметры на IS
3. Считать Sharpe на IS и OOS

**Формула:**

$$
Sharpe Decay = \frac{Sharpe_{IS} - Sharpe_{OOS}}{Sharpe_{IS}} \times 100\%
$$

**Интерпретация:**

| Decay | Оценка |
|---|---|
| < 20% | Нормально (небольшое падение) |
| 20 – 50% | Подозрительно |
| > 50% | **Переобучение** |
| OOS Sharpe < 0 | Серьёзное переобучение |

### 2. Walk-Forward Analysis

**Метод:**

1. Разделить данные на N окон
2. Каждое окно: обучение на $k$ периодов, тест на 1 период
3. Собрать OOS-метрики по всем окнам

**Критерий:** Если средний OOS Sharpe < 0.5 × средний IS Sharpe → overfitting.

### 3. Monte Carlo Permutation Test

**Метод:**

1. Посчитать Sharpe реальной стратегии: $SR_{real}$
2. Перемешать порядок сделок 1000 раз
3. Каждый раз считать Sharpe: $SR_1, SR_2, ..., SR_{1000}$
4. Найти перцентиль $SR_{real}$ в распределении $SR_{random}$

**Критерий:** Если $SR_{real}$ < 95-го перцентиля → стратегия не статистически значима.

### 4. Cross-Validation (Purged K-Fold)

**Метод:**

1. Разделить данные на K фолдов с «purge gap» (исключение наблюдений на границе)
2. Обучать на K-1 фолдах, тестировать на 1
3. Собрать метрики по всем фолдам

**Критерий:** Стандартное отклонение Sharpe по фолдам должно быть < 50% от среднего Sharpe.

### 5. Симптомы overfitting в метриках

| Симптом | Что видно |
|---|---|
| Sharpe IS >> Sharpe OOS | Decay > 50% |
| Win Rate IS ~ 90%, OOS ~ 50% | Стратегия запомнила данные |
| Нет сделок OOS | Слишком узкие фильтры |
| PF IS = 10, OOS = 0.8 | Катастрофическое падение |
| Стратегия выигрывает только на конкретных периодах | Нет робастности |
| Max Consecutive Losses OOS >> IS | Стратегия ломается в новых данных |

### 6. Deflated Sharpe Ratio

Корректирует Sharpe на количество протестированных стратегий. Если тестировали 100 стратегий и выбрали лучшую с Sharpe = 2.0, реальный DSR может быть < 1.0.

### 7. Практический чек-лист

```
[ ] Разделение на IS/OOS (70/30)
[ ] Sharpe Decay < 50%
[ ] Walk-Forward OOS Sharpe > 0.5
[ ] Monte Carlo: SR_real > 95-й перцентиль случайных
[ ] Purged CV: std(SR) / mean(SR) < 50%
[ ] ≥ 30 сделок в OOS
[ ] Все ключевые метрики OOS > 0
[ ] DSR > 0 (если доступно количество протестированных стратегий)
```

## Edge Cases и ловушки

### Ловушка 1: Высокий Sharpe ≠ прибыльность

Стратегия с Sharpe = 3.0 может иметь CAGR = 5% при низкой волатильности. Нужно смотреть на **абсолютную доходность** в дополнение к Sharpe.

### Ловушка 2: Высокий Win Rate ≠ прибыльность

95% выигрышных сделок по $1 и 5% проигрышных по $1000 = Net loss $4050.

### Ловушка 3: Низкий MaxDD ≠ хорошая стратегия

Стратегия может иметь MaxDD = 5%, но CAGR = 1%. Это неэффективное использование капитала.

### Ловушка 4: Survivorship Bias

Тестируя на текущем составе монет (топ-50), вы исключаете мёртвые монеты. Это завышает все метрики.

### Ловушка 5: Look-Ahead Bias

Использование будущих данных (даже косвенно через оптимизацию) делает бэктест бесполезным.

### Ловушка 6: Комиссии и slippage

| Фактор | Влияние |
|---|---|
| Комиссия 0.1% (taker) | Снижает PF на ~0.2 за 100 сделок |
| Slippage 0.05% | Снижает PF на ~0.1 за 100 сделок |
| Funding rate | ±0.01% каждые 8 часов на фьючерсах |

**Правило:** Всегда тестировать с комиссиями и slippage. Без них — метрики бессмысленны.

### Ловушка 7: Малый размер выборки

30 сделок — это **абсолютный минимум**. Для надёжных метрик нужно ≥ 100 сделок.

### Ловушка 8: Non-Stationarity

Крипторынок непостоянен. Стратегия, работавшая в 2021 (бычий), может не работать в 2022 (медвежий). Нужно тестировать на разных рыночных режимах.

## Имплементация: пример вычисления на Python

```python
import numpy as np
from dataclasses import dataclass

@dataclass
class TradeMetrics:
    """Вычисление всех MVP метрик из списка сделок."""
    trades: np.ndarray  # массив PnL сделок (положительный = прибыль)
    
    def total_return(self, initial_capital: float) -> float:
        return self.trades.sum() / initial_capital
    
    def cagr(self, initial_capital: float, days: float) -> float:
        final = initial_capital + self.trades.sum()
        return (final / initial_capital) ** (365.25 / days) - 1
    
    def sharpe(self, rf_daily: float = 0.0) -> float:
        excess = self.trades - rf_daily
        if excess.std() == 0:
            return float('inf')
        return excess.mean() / excess.std() * np.sqrt(365)
    
    def sortino(self, mar: float = 0.0) -> float:
        excess = self.trades - mar
        downside = excess[excess < 0]
        if len(downside) == 0:
            return float('inf')
        dd = np.sqrt((downside ** 2).mean())
        return excess.mean() / dd * np.sqrt(365)
    
    def max_drawdown(self, initial_capital: float) -> float:
        equity = initial_capital + np.cumsum(self.trades)
        peak = np.maximum.accumulate(equity)
        dd = (peak - equity) / peak
        return dd.max()
    
    def win_rate(self) -> float:
        return (self.trades > 0).sum() / len(self.trades)
    
    def profit_factor(self) -> float:
        wins = self.trades[self.trades > 0].sum()
        losses = abs(self.trades[self.trades < 0].sum())
        return wins / losses if losses > 0 else float('inf')
    
    def expectancy(self) -> float:
        return self.trades.mean()
    
    def recovery_factor(self, initial_capital: float) -> float:
        net = self.trades.sum()
        mdd = self.max_drawdown(initial_capital) * initial_capital
        return net / mdd if mdd > 0 else float('inf')
    
    def payoff_ratio(self) -> float:
        avg_win = self.trades[self.trades > 0].mean()
        avg_loss = abs(self.trades[self.trades < 0].mean())
        return avg_win / avg_loss if avg_loss > 0 else float('inf')
    
    def calmar(self, initial_capital: float, days: float) -> float:
        cagr = self.cagr(initial_capital, days)
        mdd = self.max_drawdown(initial_capital)
        return cagr / mdd if mdd > 0 else float('inf')
    
    def max_consecutive_losses(self) -> int:
        max_run = run = 0
        for t in self.trades:
            if t < 0:
                run += 1
                max_run = max(max_run, run)
            else:
                run = 0
        return max_run
    
    def omega(self, threshold: float = 0.0) -> float:
        excess = self.trades - threshold
        gains = excess[excess > 0].sum()
        losses = abs(excess[excess < 0].sum())
        return gains / losses if losses > 0 else float('inf')
```
