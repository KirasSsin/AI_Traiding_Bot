# EMA и RSI: скользящие средние и индекс силы

**TL;DR:** EMA — «умная» скользящая средняя, которая быстрее реагирует на свежие цены. RSI — термометр, показывающий, «перегрелся» рынок или «переохладился». Бот использует EMA-пересечения и RSI-фильтры для входа и выхода из сделок в двух стратегиях: EMA Crossover и Mean Reversion.

---

## Простыми словами

### Что такое скользящая средняя

Представьте, что вы следите за ценой BTC каждый час. Сегодня — 65 000 $, вчера — 63 000 $, позавчера — 67 000 $. Разобраться в этом «шуме» сложно. Скользящая средняя (Moving Average) решает эту задачу: она берёт несколько последних значений и считает их среднее, «скользя» по времени вместе с рынком.

Обычная средняя (SMA) — простое среднее за N часов, каждый час весит одинаково. **EMA (Exponential Moving Average, экспоненциальная скользящая средняя)** умнее: она даёт больший вес свежим ценам и постепенно «забывает» старые. Благодаря этому EMA реагирует на разворот быстрее, чем SMA с тем же периодом.

Аналогия: представьте, что вы оцениваете настроение сотрудника. Обычная средняя учитывает всю неделю поровну. EMA скажет: «вчерашний и сегодняшний день важнее, чем понедельник». Поэтому EMA точнее отражает текущее состояние.

### Что такое RSI

**RSI (Relative Strength Index, индекс относительной силы)** — это термометр рынка, показывающий, насколько «перекуплен» или «перепродан» актив прямо сейчас. Диапазон: от 0 до 100.

- RSI выше 70 — рынок «перекуплен»: цена выросла слишком быстро, возможен откат вниз.
- RSI ниже 30 — рынок «перепродан»: цена упала слишком резко, возможен отскок вверх.

Аналогия: RSI — как давление котла. Если давление слишком высокое (RSI > 70), котёл может «взорваться» (откат). Если давление слишком низкое (RSI < 30), нужно «подкинуть угля» (отскок вверх).

RSI считает, насколько в среднем цена росла по сравнению с тем, насколько она падала за последние N свечей. Если роста было намного больше — RSI высокий, и наоборот.

## Как это работает у нас

### Функция `ema()` — два режима сглаживания

Файл: `src/signalgen/indicators.py`, строки 14–44.

Бот реализует EMA с двумя режимами, которые отличаются ровно одним числом — сглаживающим коэффициентом **α (альфа)**. Альфа определяет, насколько быстро «забываются» старые значения:

| Режим | Формула α | Где применяется |
|-------|-----------|-----------------|
| `"classical"` (классический) | `α = 2 / (n + 1)` | EMA Crossover стратегия |
| `"wilder"` (сглаживание Уайлдера) | `α = 1 / n` | RSI, [[adx-indicator\|ADX]], [[atr-indicator\|ATR]] |

Почему два режима? Это решение принято в ADR 0011: исторически Уайлдер (автор RSI и ADX в 1978 году) использовал собственную более «медленную» формулу α = 1/n. Если перемешать режимы — значения индикаторов разойдутся с TradingView и биржевыми чартами, что делает сравнение бессмысленным. `src/signalgen/indicators.py:26–27`.

**Классический режим** (строка 34) — делегирует вычисление библиотеке TA-Lib одной строкой:

```python
return talib.EMA(close, timeperiod=period)
```

Период `n` задаётся в `config.yaml`: `fast_period: 12`, `slow_period: 120`. `config.yaml:25–26`.

**Режим Wilder** (строки 35–44) — реализован вручную с нуля:

```python
seed = np.mean(close[:period])       # начальное значение = среднее первых N свечей (SMA-seed)
result[period - 1] = seed
alpha = 1.0 / period
for t in range(period, len(close)):
    result[t] = alpha * close[t] + (1.0 - alpha) * result[t - 1]
```

Первые `period - 1` значений — всегда `NaN` (не хватает данных для прогрева). Первое рабочее значение — это простое среднее первых `period` свечей (**SMA-seed**, «затравка» через простую среднюю). Затем на каждой новой свече применяется рекуррентная формула. `src/signalgen/indicators.py:36–44`.

### Функция `rsi()` в реальном времени — сглаживание Уайлдера через TA-Lib

Файл: `src/signalgen/indicators.py`, строки 47–64.

Для сигналов в реальном времени (стратегии [[02-стратегии/ema-crossover-strategy|EMA Crossover]] `EmaCrossoverAdxRsiStrategy` и [[02-стратегии/mean-reversion-strategy|Mean Reversion]] `MeanReversionRsiBBStrategy`) бот вычисляет RSI одной строкой через TA-Lib:

```python
return talib.RSI(close, timeperiod=period)
```

TA-Lib применяет именно сглаживание Уайлдера (α = 1/period), как и оригинал 1978 года. Диапазон значений: **[0, 100]**. Первые `period` значений — `NaN`. `src/signalgen/indicators.py:60–64`.

Период по умолчанию — 14 (стандарт Уайлдера). В `config.yaml` — `period: 14` (строка 29).

### RSI в бэктесте — pandas ewm вместо TA-Lib

Файл: `src/backtest/indicators.py`, строки 88–100.

В функции [[indicators-and-signals|`calculate_indicators()`]] бот вычисляет RSI иначе — через pandas:

```python
delta = out["close"].diff()
gain = delta.where(delta > 0, 0.0).ewm(alpha=1 / rsi_period, adjust=False).mean()
loss = (-delta.where(delta < 0, 0.0)).ewm(alpha=1 / rsi_period, adjust=False).mean()
rs = gain / loss.replace(0, np.nan)
rsi = 100 - (100 / (1 + rs))
# Принудительно NaN для первых rsi_period баров (warm-up)
rsi.iloc[:rsi_period] = np.nan
```

Математика — та же самая (Wilder, α = 1/period), только инструмент другой: `pandas.ewm` вместо TA-Lib. Главная деталь — **строка `rsi.iloc[:rsi_period] = np.nan`** (строка 99): первые `rsi_period` баров принудительно обнуляются в `NaN`. Это исправление ошибки S27 T3: прежняя версия заполняла прогревочные бары значением 50.0, из-за чего EMA Crossover мог ложно открывать позиции ещё до того, как RSI успевал «прогреться». `src/backtest/indicators.py:88–100`.

Аналогично обнуляются первые `atr_period` баров ATR — строки 102–109.

### EMA Crossover — когда бот входит в сделку

Файл: `src/backtest/indicators.py`, строки 182–196; `src/signalgen/strategy.py`, строки 123–144.

**Сигнал на вход** возникает, когда выполняются **оба условия одновременно**:

1. **EMA-пересечение снизу вверх**: быстрая EMA (`ema_fast`) была ниже медленной EMA (`ema_slow`) на предыдущем баре — и поднялась выше на текущем. Это сигнал смены тренда: рынок начинает расти.

2. **RSI не перекуплен**: `RSI < overbought`. В `config.yaml` порог: `overbought: 68` (строка 30). Смысл: если рынок и так перегрет (RSI ≥ 68), входить уже поздно — разворот может быть рядом.

В бэктесте (`calculate_indicators`):

```python
cross_up = (out["ema_fast"].shift(1) <= out["ema_slow"].shift(1)) & (
    out["ema_fast"] > out["ema_slow"]
)
overbought = float(rsi_cfg.get("overbought", 68))
signal[np.where(cross_up & (out["rsi"] < overbought))[0]] = 1
```

`src/backtest/indicators.py:182–188`.

В реальном времени (`EmaCrossoverAdxRsiStrategy`) к этим двум условиям добавляются ещё два: ADX > порога (сильный тренд) и +DI > -DI (бычье направление). `src/signalgen/strategy.py:124–136`.

Параметры EMA из `config.yaml`: быстрая — 12 баров, медленная — 120 баров. `config.yaml:25–26`.

### Mean Reversion — возврат к среднему

Файл: `src/signalgen/mean_reversion_strategy.py`, строки 43–52, 166–184.

**Смысл стратегии**: если цена упала слишком далеко от своего «нормального» уровня, она скорее всего вернётся обратно. Бот покупает в момент «максимальной паники». Аналогия: если хлеб в магазине вдруг подешевел вдвое — вы покупаете запас, потому что цена явно временная.

**Сигнал на вход** — AND-gate (оба условия строго обязательны, ADR 0030):

1. `RSI < rsi_oversold` — рынок «перепродан».
2. `close < lower_BB` — цена пробила нижнюю [[bollinger-bands-indicator|полосу Боллинджера]] (дополнительное подтверждение паники).

Если выполнено только одно из двух — сигнала нет. Это осознанное решение (ADR 0030): одиночный RSI-сигнал давал слишком много ложных срабатываний.

**Сигнал на выход** — OR-gate (достаточно одного из двух):

- `RSI > rsi_overbought` — рынок «перекуплен», возврат к норме состоялся.
- `close > upper_BB` — цена пробила верхнюю полосу, рост завершён.

`src/signalgen/mean_reversion_strategy.py:166–184`.

### LOCKED параметры стратегии Mean Reversion

Файл: `src/signalgen/mean_reversion_strategy.py`, строки 43–52.

Параметры Mean Reversion **жёстко зафиксированы** в именованной константе `MEAN_REVERSION_S17_RELAXED_PARAMS`. Изменять их нельзя без пересогласования статистики ([[dsr-metric|DSR]], [[mc-permutation-test|MC-тест]]):

```python
MEAN_REVERSION_S17_RELAXED_PARAMS = MappingProxyType({
    "rsi_period":    14,
    "rsi_oversold":  Decimal("35"),   # не 30 (S15 параметр давал шум, MC p=0.998)
    "rsi_overbought": Decimal("65"),  # не 70 (S15 параметр давал шум)
    "bb_period":     20,
    "bb_std_mult":   1.5,             # не 2.0 (S15 параметр давал шум)
    "and_gate_required": True,
})
```

`src/signalgen/mean_reversion_strategy.py:43–52`.

Тип `MappingProxyType` — это словарь-«замок»: любая попытка изменить значение из кода или теста вызовет `TypeError`. Это защита от случайного возврата к плохим параметрам Sprint 15, у которых Monte Carlo p-value = 0.998 (означает: 99.8% шанс, что результат случаен, то есть стратегия не работает). Текущие «relaxed» параметры прошли валидацию: MC p = 0.018. `src/signalgen/mean_reversion_strategy.py:36–52`.

## Формулы и расчёты

### EMA — рекуррентная формула

```
EMA[t] = α × цена[t] + (1 − α) × EMA[t−1]
```

Расшифровка простыми словами: новое значение EMA = маленький кусочек от сегодняшней цены плюс большой кусочек от вчерашней EMA. Чем меньше α, тем «инертнее» средняя, тем медленнее она реагирует на изменения.

- Классический: `α = 2 / (n + 1)`. Для n=12: `α ≈ 0.154` (15.4% — текущая цена).
- Уайлдер: `α = 1 / n`. Для n=14: `α ≈ 0.071` (7.1% — текущая цена, более «медленный» отклик).

Наша реализация — `src/signalgen/indicators.py:41–43`.

### RSI — формула Уайлдера 1978

**Шаг 1.** Считаем изменения цены за каждый бар: рост (gain) и потеря (loss).

**Шаг 2.** Вычисляем среднее через сглаживание Уайлдера (EMA с α = 1/period):
- `avg_gain` = Wilder-EMA всех приростов за period баров
- `avg_loss` = Wilder-EMA всех потерь за period баров (по модулю)

**Шаг 3.** RS = avg_gain / avg_loss (соотношение среднего роста к среднему падению)

**Шаг 4.**
```
RSI = 100 − (100 / (1 + RS))
```

Расшифровка: если рынок рос в 9 раз сильнее, чем падал (`RS = 9`), то `RSI = 100 − 100/10 = 90` — сильно перекуплен. Если поровну (`RS = 1`): `RSI = 50` — нейтрально. Если только падал (`RS → 0`): `RSI → 0` — сильно перепродан.

Наша реализация в бэктесте — `src/backtest/indicators.py:93–100`; в реальном времени — `talib.RSI` с тем же сглаживанием `src/signalgen/indicators.py:64`.

### Полосы Боллинджера — для Mean Reversion

```
Middle = SMA(close, 20)            — простое среднее за 20 баров
Upper  = Middle + 1.5 × σ          — верхняя граница (σ = стандартное отклонение)
Lower  = Middle − 1.5 × σ          — нижняя граница
```

Расшифровка: σ (сигма) — мера разброса цен. Чем волатильнее рынок, тем шире полосы. `close < Lower` означает: цена упала настолько ниже нормы, что это редкость — бот считает это сигналом к покупке.

LOCKED параметры нашей стратегии: `bb_period = 20`, `bb_std_mult = 1.5` (стандартное отклонение по генеральной совокупности, `ddof=0`). `src/signalgen/bollinger_bands.py:50`, `src/signalgen/mean_reversion_strategy.py:49`.

## Примеры / сценарии

### Сценарий A: EMA Crossover срабатывает

Представьте 5 последних часовых свечей BTC (цены условные):

| Час | Цена | EMA(12) | EMA(120) | RSI(14) |
|-----|------|---------|---------- |---------|
| T-2 | 63 000 | 62 900 | 63 200 | 62 |
| T-1 | 63 500 | 63 050 | 63 200 | 64 |
| T   | 64 000 | 63 250 | 63 220 | 66 |

На баре T-1: EMA(12) = 63 050 < EMA(120) = 63 200 (быстрая ниже медленной).
На баре T: EMA(12) = 63 250 > EMA(120) = 63 220 (быстрая поднялась выше) — **пересечение снизу вверх**.
RSI(14) = 66 < 68 (порог из `config.yaml`) — **не перекуплен**.

Оба условия выполнены → бот выставляет сигнал на покупку. Фактическая покупка произойдёт на открытии следующего бара (T+1) — это принцип look-ahead safety, описанный в [[06-бэктест-и-валидация/replay-engine-bar-by-bar]].

### Сценарий B: Mean Reversion срабатывает

BTC упал за несколько часов. Снапшот:

| Показатель | Значение | Порог |
|------------|---------|-------|
| RSI(14) | 31 | < 35 (LOCKED rsi_oversold) |
| close | 58 200 $ | < lower_BB = 58 500 $ |

RSI = 31 < 35 ✓ И close = 58 200 < 58 500 ✓ → **оба условия выполнены**, бот генерирует сигнал LONG.

Если RSI = 31, но close = 58 600 > 58 500 — сигнала нет. Одного RSI недостаточно.

### Сценарий C: Warm-up блокирует первые сигналы

Бэктест запускается с нуля на исторических данных. Первые 14 баров RSI = NaN. Пока RSI не вычислен, бот физически не может проверить условие `RSI < overbought` — функция `on_bar()` возвращает `None` без сигнала (единый паттерн [[signal-architecture|архитектуры сигналов]]).

Для EMA Crossover дополнительно нужно дождаться 120 баров для медленной EMA — только после этого обе EMA дают валидные значения и пересечение можно фиксировать. `src/signalgen/strategy.py:92`.

## Подводные камни / что важно понимать

### 1. Прогрев индикатора — первые N свечей всегда пустые

Это не ошибка, а математическая необходимость. RSI(14) не может быть вычислен на 13 свечах — просто не хватает данных для рекуррентной формулы. Функция `rsi()` возвращает `NaN` для первых `period` баров — и код явно проверяет наличие `NaN` перед принятием решения. `src/signalgen/mean_reversion_strategy.py:160`.

Если в коде когда-либо заменить `NaN` на заглушку вроде `50.0` — бот будет открывать сделки в период «слепоты» (именно этот баг был в версии до S27 T3). `src/backtest/indicators.py:88–91`.

### 2. Два RSI в проекте — одна математика, разная реализация

- **Реальное время**: `talib.RSI()` (`src/signalgen/indicators.py:64`).
- **Бэктест**: `pandas ewm` с принудительным NaN-masking (`src/backtest/indicators.py:94–99`).

Математически оба дают Wilder-RSI с α = 1/period. Различие — в инструменте. Принудительный NaN-mask в бэктесте (`rsi.iloc[:rsi_period] = np.nan`) добавлен явно, потому что `pandas ewm` без `adjust=False` в некоторых версиях может не гарантировать NaN на прогреве. `src/backtest/indicators.py:98–99`.

### 3. LOCKED параметры Mean Reversion нельзя менять произвольно

Параметры `rsi_oversold=35`, `rsi_overbought=65`, `bb_std_mult=1.5` прошли статистическую проверку (DSR=1.0, MC p=0.018). Параметры Sprint 15 (`30/70`, `2σ`) дали MC p=0.998 — статистический мусор. Константа `MEAN_REVERSION_S17_RELAXED_PARAMS` намеренно упакована в `MappingProxyType` — изменить её из кода нельзя физически, это вызовет `TypeError`. `src/signalgen/mean_reversion_strategy.py:36–52`.

### 4. EMA в стратегии использует «classical», не «wilder»

Для EMA Crossover бот всегда вызывает `ema(closes, period, mode="classical")`, а не Wilder. RSI и ADX, наоборот, используют Wilder. Причина — в ADR 0011: классические EMA соответствуют стандартным чартам (TradingView, Murphy, Pring), а индикаторы Уайлдера — оригинальным формулам 1978 года. `src/signalgen/strategy.py:101–106`.

### 5. Два EMA, два ATR — не дублирование, а намеренные варианты

В проекте существует несколько реализаций ATR: `atr()` через TA-Lib, [[wilder-atr-and-stops|`wilder_atr()`]] ручная, и EWM-вариант в бэктесте. Каждая используется строго своей стратегией. Объединять их нельзя — разница составляет около 1.4%, что влияет на результаты WFA. Подробнее — [[03-индикаторы-и-расчёты/atr-indicator]].
