# Стратегия Supertrend (Lazybear вариант)

**TL;DR:** Бот следит за адаптивной трендовой линией — Supertrend. Как только цена пробивает её снизу вверх, бот покупает; как только цена падает ниже — продаёт. Стратегия работает только в лонг (покупки) и не может открывать короткие позиции.

## Простыми словами

Представьте, что вы едете на автомобиле по шоссе, а рядом — защитный отбойник. Пока дорога ровная, отбойник идёт параллельно вам — он не прыгает вниз, а плавно следует за дорогой. Если вы уходите вправо и задеваете его — значит, «тренд сломался» и пора остановиться.

Supertrend — это именно такой «отбойник» для цены. Бот рисует линию рядом с ценой актива (в нашем случае — биткоина, BTC/USDT на часовом графике). Эта линия двигается адаптивно: она учитывает насколько «шумно» рынок себя ведёт (через [[03-индикаторы-и-расчёты/supertrend-indicator|ATR — средний диапазон движения цены за бар]]).

- Когда цена выше линии — тренд бычий (**BULL**): бот держит позицию или ждёт входа.
- Когда цена опускается ниже линии — тренд медвежий (**BEAR**): бот выходит.

Особенность «Lazybear варианта» — у линии есть **«храповик»** (ratchet): в бычьем тренде нижняя полоса может только подниматься (никогда не опускается вниз), что даёт поднимающийся «гарантированный пол». В медвежьем — верхняя полоса только опускается. Это делает линию устойчивой к кратковременным колебаниям.

> Параметры стратегии **зафиксированы раз и навсегда** решением ADR 0067 (anti-snooping pre-registration, Sprint 50): `atr_period=10`, `multiplier=3.0`. Менять их без нового ADR запрещено.

## Как это работает у нас

### Шаг 0. Инициализация

При создании стратегии в памяти бота появляются нулевые «несущие» переменные (carry state): предыдущий ATR, предыдущие значения верхней/нижней полосы, предыдущая supertrend-линия. Все они `None` — сигналов ещё не будет, пока не накопится достаточно баров.

```python
# src/signalgen/supertrend_strategy.py:89-121
self._prev_atr: float | None = None
self._prev_final_ub: float | None = None
self._prev_final_lb: float | None = None
self._supertrend_line: float | None = None
self._trend_direction: Literal["BULL", "BEAR"] | None = None
```

Фиксированные параметры живут в словаре `SUPERTREND_LOCKED_PARAMS` и считываются при создании объекта `SupertrendStrategy`:

```python
# src/signalgen/supertrend_strategy.py:63-67
SUPERTREND_LOCKED_PARAMS: dict[str, object] = {
    "atr_period": 10,
    "multiplier": Decimal("3.0"),
    "signal_side_mode": "long_only",
}
```

### Шаг 1. Метод `on_bar` — главная точка входа

Каждый раз, когда закрывается новая часовая свеча (бар), бот вызывает `on_bar(bar)`. Этот метод — единственная «входная точка» стратегии. Он возвращает либо объект [[02-стратегии/signal-architecture|`Signal`]] (сигнал), либо `None` (нет действия).

**Три охранника на входе** `(src/signalgen/supertrend_strategy.py:136–142)`:

1. **Незакрытый бар** — если бар ещё не закрыт (`bar.is_closed = False`), метод немедленно возвращает `None`. Бот не реагирует на незакрытые свечи — это защита от ложных срабатываний.
2. **Старый или дублирующийся бар** — если `bar.close_time` не строго позже последнего обработанного времени, бар отклоняется. Защита от ситуации, когда биржа присылает одно и то же дважды или в неправильном порядке (out-of-order, OOO).
3. **Период прогрева** — ATR требует накопить `atr_period = 10` баров, прежде чем выдать первое валидное значение. Пока ATR не рассчитан, `on_bar` возвращает `None`.

### Шаг 2. Расчёт ATR (метод `_update_atr`)

[[03-индикаторы-и-расчёты/atr-indicator|**ATR**]] (Average True Range, средний истинный диапазон) — число, которое показывает насколько сильно цена двигалась в последние периоды. Если цена скачет на 1000 рублей туда-сюда — ATR высокий; если всё тихо — ATR низкий. Бот использует его для масштабирования «ширины коридора» вокруг цены.

Наша реализация использует [[06-бэктест-и-валидация/wilder-atr-and-stops|**полноисторический Wilder RMA**]] — рекуррентную формулу, которая работает инкрементально: каждый новый бар обновляет одно число, не перечитывая всю историю. Это O(1) памяти — никакого буфера из `atr_period` баров:

```text
Первый бар: TR[0] = high[0] − low[0]  (нет предыдущего close)
Последующие: TR[i] = max(high−low, |high−prev_close|, |low−prev_close|)
Прогрев (первые 10 баров): накапливаем TR в список _tr_seed
Seed-бар (10-й бар): ATR = среднее первых 10 TR
Дальше: ATR = (ATR × (period − 1) + TR) / period
```

`(src/signalgen/supertrend_strategy.py:208–242)`

**Почему полноисторический?** Если пересчитывать ATR только по последним `atr_period` барам (скользящее окно), то каждый раз при «сдвиге» окна Wilder-рекуррентность начинается заново. Это создаёт смещение относительно эталона. Тест T5 (`tests/property/test_supertrend_lookahead.py:192–217`) проверяет точное совпадение потокового и векторизованного (эталонного) ATR с точностью 1e-9.

### Шаг 3. Базовые и финальные полосы

После расчёта ATR бот вычисляет **hl2** — среднюю цену бара:

```
hl2 = (high + low) / 2
```

Затем строит **базовые полосы** (сырые, без храповика):

```
basic_ub = hl2 + 3.0 × ATR   (верхняя полоса)
basic_lb = hl2 − 3.0 × ATR   (нижняя полоса)
```

Это просто «разброс» на 3 средних диапазона выше и ниже середины свечи. Но эти сырые значения скачут вместе с ценой, что создало бы много ложных сигналов. Именно тут подключается **храповик Lazybear**.

`(src/signalgen/supertrend_strategy.py:154–185)`

### Шаг 4. Lazybear «храповик» (ratchet/clamp)

Это ключевая особенность, отличающая Lazybear-вариант от «простого» Supertrend.

**Правило для верхней полосы `final_ub`:**

```
final_ub = basic_ub  ТОЛЬКО если:
  1. basic_ub < prev_final_ub    (новая полоса ниже — полоса «сжалась»)
  ИЛИ
  2. prev_close > prev_final_ub  (цена закрылась выше предыдущей верхней — был пробой)
В ОСТАЛЬНЫХ СЛУЧАЯХ: final_ub = prev_final_ub  (полоса «заморозилась»)
```

`(src/signalgen/supertrend_strategy.py:180–182)`

Простыми словами: **верхняя полоса только опускается (или остаётся на месте), никогда не поднимается против медвежьего тренда**. Это как потолок, который давит всё ниже.

**Правило для нижней полосы `final_lb`:**

```
final_lb = basic_lb  ТОЛЬКО если:
  1. basic_lb > prev_final_lb    (новая полоса выше — пол «поднялся»)
  ИЛИ
  2. prev_close < prev_final_lb  (цена закрылась ниже — был пробой)
В ОСТАЛЬНЫХ СЛУЧАЯХ: final_lb = prev_final_lb  (пол «заморозился»)
```

`(src/signalgen/supertrend_strategy.py:183–185)`

Простыми словами: **нижняя полоса только поднимается, никогда не опускается в бычьем тренде**. Это как пол, который постепенно поднимается вслед за ценой.

Тест `test_lazybear_latch_bull_non_decreasing` в `tests/unit/test_supertrend_strategy.py:198–215` проверяет это свойство числово: при устойчивом бычьем тренде каждое новое значение нижней полосы >= предыдущего с точностью 1e-9.

### Шаг 5. Выбор активной линии Supertrend

Какую из двух полос сейчас «отслеживать» как активную линию — решается на основе **предыдущей активной линии**:

```python
# src/signalgen/supertrend_strategy.py:188–191
if prev_supertrend == prev_final_ub:
    supertrend = final_ub if close <= final_ub else final_lb
else:
    supertrend = final_lb if close >= final_lb else final_ub
```

Логика:
- Была активна **верхняя** полоса (медвежий режим): остаёмся на верхней, пока цена ≤ final_ub; если цена закрылась выше — переключаемся на нижнюю (бычий переворот).
- Была активна **нижняя** полоса (бычий режим): остаёмся на нижней, пока цена ≥ final_lb; если цена закрылась ниже — переключаемся на верхнюю (медвежий переворот).

Это и есть «рекурсивность» индикатора: направление тренда на баре `i` зависит от `close[i]` и от того, где была активная линия на баре `i-1`.

### Шаг 6. Определение тренда

```python
# src/signalgen/supertrend_strategy.py:193
trend: Literal["BULL", "BEAR"] = "BULL" if supertrend == final_lb else "BEAR"
```

- **BULL** — активная линия равна нижней полосе: цена выше «пола», тренд восходящий.
- **BEAR** — активная линия равна верхней полосе: цена под «потолком», тренд нисходящий.

### Шаг 7. Сигналы (метод `_evaluate_flip`)

Сигнал генерируется **только при смене тренда** — флипе (flip). В середине тренда сигналов нет.

```python
# src/signalgen/supertrend_strategy.py:252–268
# Вход: BEAR → BULL, находимся в FLAT
if prev_trend == "BEAR" and trend == "BULL" and self._current_side == SignalSide.FLAT:
    self._current_side = SignalSide.LONG
    return self._build_signal(bar, SignalSide.LONG, ..., reason=ReasonCode.ENTRY_LONG_SUPERTREND)

# Выход: BULL → BEAR, находимся в LONG
if prev_trend == "BULL" and trend == "BEAR" and self._current_side == SignalSide.LONG:
    self._current_side = SignalSide.FLAT
    return self._build_signal(bar, SignalSide.FLAT, ..., reason=ReasonCode.EXIT_FLAT_SUPERTREND_FLIP)
```

| Событие | Код причины | Новое состояние |
|---|---|---|
| BEAR → BULL (были FLAT) | `ENTRY_LONG_SUPERTREND` | LONG |
| BULL → BEAR (были LONG) | `EXIT_FLAT_SUPERTREND_FLIP` | FLAT |
| Без смены тренда | — | без изменений |

`(src/risk/reason_codes.py:147–148)` — коды добавлены в Sprint 50 решением ADR 0067.

**Важно:** стратегия **никогда не emitит SHORT**. Это spot-only бот, и `signal_side_mode = "long_only"` — инвариант.

return Signal(

Поля `ema_fast`, `ema_slow`, `adx_14`, `rsi_14` заполняются нулём-заглушкой — Supertrend их не считает. Единственный «живой» индикатор в сигнале — `atr_14`, который передаётся downstream в [[05-исполнение-ордеров/execution-state-machine|FSM (конечный автомат исполнения)]] для расчёта [[05-исполнение-ордеров/oco-bracket-emulation|ATR-брекета стоп-лосса]].

### Шаг 9. Seed bar — первый валидный бар

Первый бар, на котором ATR становится валидным (10-й по счёту), называется **seed bar**. На нём:

- Верхняя и нижняя полосы инициализируются текущими значениями `basic_ub` / `basic_lb`.
- Активная линия устанавливается на **верхнюю** полосу (`supertrend_line = basic_ub`).
- Направление — **BEAR** (консервативный старт: бот не прыгает в рынок сразу).
- Сигнала нет — нет предыдущего состояния для сравнения.

`(src/signalgen/supertrend_strategy.py:158–171)`

Следовательно, реальный первый сигнал возможен не ранее 11-го бара (seed + 1).

## Формулы и расчёты

### hl2 — середина свечи

```
hl2 = (high + low) / 2
```

**Что считает:** среднее между максимумом и минимумом часового бара. Это «центр» рыночной активности за час, более стабильный, чем close (цена закрытия), которая может быть случайной.

### Базовые полосы

```
basic_ub = hl2 + multiplier × ATR   = hl2 + 3.0 × ATR   (верхняя, «потолок»)
basic_lb = hl2 − multiplier × ATR   = hl2 − 3.0 × ATR   (нижняя, «пол»)
```

**Что считает:** «коридор» шириной 3 ATR вокруг середины свечи. Чем больше ATR (рынок шумный) — тем шире коридор, тем труднее его пробить и получить сигнал.

`(src/signalgen/supertrend_strategy.py:154–156)`

### Lazybear clamp (храповик)

```
final_ub = basic_ub  если (basic_ub < prev_final_ub) ИЛИ (prev_close > prev_final_ub)
           иначе prev_final_ub

final_lb = basic_lb  если (basic_lb > prev_final_lb) ИЛИ (prev_close < prev_final_lb)
           иначе prev_final_lb
```

**Что считает:** сглаженные полосы, которые «застывают» в выгодном направлении и не двигаются против тренда. Верхняя только опускается, нижняя только поднимается — пока тренд не сломается.

`(src/signalgen/supertrend_strategy.py:180–185)`

### Wilder ATR (инкрементальный)

```
TR[0]  = high[0] − low[0]
TR[i]  = max(high−low, |high−prev_close|, |low−prev_close|)

Seed-ATR (бар №9 = 10-й бар): ATR = mean(TR[0..9])   (среднее первых 10 TR)
ATR[i]            = (ATR[i-1] × 9 + TR[i]) / 10   (сглаживание Уайлдера)
```

**Что считает:** взвешенное среднее «истинных диапазонов» последних баров. Wilder-сглаживание означает, что старые бары влияют всё меньше, но **никогда не забываются полностью** — именно поэтому мы не пересчитываем ATR из скользящего окна, а ведём одно число.

`(src/signalgen/supertrend_strategy.py:208–242)`, `(src/signalgen/indicators.py:84–124)` — эталонная векторная реализация.

## Примеры / сценарии

### Сценарий: вход в позицию

Представим упрощённую ситуацию. Биткоин держится на уровне 100 тысяч долларов, рынок спокойный (ATR ≈ 1000 долларов). Нижняя полоса Supertrend находится примерно на отметке 97000 (100000 − 3 × 1000). Бот в состоянии FLAT (нет позиции), тренд BEAR (начальное состояние после seed-бара).

1. **Бары 1–9:** бот накапливает историю для ATR, сигналов нет.
2. **Бар 10 (seed):** ATR готов, полосы инициализированы, тренд = BEAR. Сигнала нет — нет предыдущего состояния для сравнения. `(src/signalgen/supertrend_strategy.py:232–237)`
3. **Бары 11–29:** цена остаётся ниже верхней полосы, тренд = BEAR, сигналов нет.
4. **Бар 30:** цена резко взлетает до 104000, закрывается выше final_ub (≈ 103000). Активная линия переключается с верхней на нижнюю → **тренд становится BULL**. Это BEAR → BULL флип при состоянии FLAT → бот emitит сигнал `ENTRY_LONG_SUPERTREND`.
5. **Следующий бар (31):** FSM читает сигнал и выставляет ордер на покупку по открытию бара 31 (open[31]) с небольшим дополнительным проскальзыванием.

**Почему fill на баре 31, а не 30?** Потому что флип решается на основе close[30], который стал известен только в момент закрытия бара 30. Физически исполнить ордер по open[30] невозможно — бар 30 уже закрылся. Самая ранняя точка исполнения — открытие следующего бара: open[31]. Это подтверждает тест в `tests/property/test_supertrend_lookahead.py:375–402`.

### Сценарий: выход из позиции

Бот держит LONG позицию, тренд BULL, нижняя полоса неуклонно поднимается (храповик в действии). Вдруг рынок разворачивается:

1. Цена закрывается ниже текущей нижней полосы final_lb.
2. Активная линия переключается на верхнюю → **тренд становится BEAR**.
3. BULL → BEAR флип при состоянии LONG → бот emitит `EXIT_FLAT_SUPERTREND_FLIP`.
4. FSM читает сигнал и продаёт позицию на открытии следующего бара.

Никакого тейк-профита у стратегии нет — только выход по смене тренда. Стоп-лосс (ATR-брекет) — это отдельный механизм FSM, который использует `atr_14` из сигнала, но это уже за пределами данной страницы.

## Подводные камни / что важно понимать

### Минимум 10 баров без сигналов; первый сигнал возможен на 11-м баре

На часовом графике это 10 часов после старта стратегии, во время которых бот не может ни войти, ни выйти. Первые 9 баров идут на накопление TR; 10-й бар — seed: ATR рассчитан впервые, полосы инициализированы, но сигнала нет (нет предыдущего состояния). Первый возможный сигнал — на 11-м баре. `(src/signalgen/supertrend_strategy.py:232–237, 158–171)` Запускать стратегию «прямо сейчас» и ожидать немедленной реакции не следует.

### Консервативный старт: seed-бар всегда BEAR

Seed-бар намеренно инициализируется с трендом BEAR и активной линией на верхней полосе (`src/signalgen/supertrend_strategy.py:168–169`). Это значит, что первый возможный сигнал — только вход (BEAR → BULL). Бот никогда не входит «по умолчанию» при старте.

### Рекурсивность — почему fill всегда на следующем баре

Тренд на баре `i` зависит от `close[i]`. Это делает индикатор **рекурсивным**: невозможно знать направление тренда до того, как бар закрылся. Поэтому:

- Сигнал порождается по `close[i]`.
- Исполнение — по `open[i+1]`.

Любая попытка исполнить по `open[i]` — это заглядывание в будущее (same-bar look-ahead), что даёт нереалистичные результаты в [[06-бэктест-и-валидация/what-is-backtest-overview|бэктесте]]. В тестах для этого специально проставлены «абсурдные» цены открытия флип-баров (`open[30] = 1_000_000`), чтобы look-ahead был мгновенно заметен. `(tests/property/test_supertrend_lookahead.py:329–402)`

### Нет тейк-профита — только флип или ATR-стоп

Стратегия сама по себе **не знает о прибыльных целях**. Выход — либо по обратному флипу тренда (EXIT_FLAT_SUPERTREND_FLIP), либо по ATR-брекету, который настраивает downstream FSM и [[04-риск-менеджмент/risk-overview-decision-pipeline|риск-менеджер]]. Если рынок тихо ползёт вверх годами — бот будет держать позицию годами. Это осознанный выбор «следования за трендом», а не упущение.

### O(1) память — нет буфера баров

Стратегия не хранит историю баров. Всё состояние — пять `float`-переменных carry: `prev_atr`, `prev_final_ub`, `prev_final_lb`, `supertrend_line`, `prev_close`. Это делает стратегию эффективной по памяти, но также означает: если процесс перезапустится, carry-состояние утрачивается и стратегия начинает с нуля (прогрев заново).

### Параметры залочены — любое изменение требует ADR

`atr_period=10` и `multiplier=3.0` — это не настройки конфигурационного файла, а **pre-registered hypothesis** (гипотеза #10, зарегистрированная ДО того, как посмотрели на результаты). Изменение без нового ADR означало бы «подгонку под данные» и обесценило бы результаты бэктеста. `(src/signalgen/supertrend_strategy.py:62–67)`
